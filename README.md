# **SQL_Project_Music_Store_Analysis**

SQL project to analyze online music store data

This project is for SQL basic unnderstanding and it will taught how to analyze the music playlist database. We can examine the dataset with SQL and help the store to understand its business growth by answering simple questions answers.

### Music_Store_Analysis_SQL_Project

**1. Objective:**
The goal of this project is to analyze sales data for a music store to identify patterns, optimize inventory, and increase profitability. The store's management faces challenges in understanding customer preferences, tracking popular genres, and forecasting future sales trends. The analysis aims to provide actionable insights to enhance business performance and customer satisfaction.

**2. Project Description:**
This project involves analyzing transactional data from a music store to uncover trends in customer behavior and sales performance. The dataset includes information about sales, customers, music tracks, genres, and employee performance. Key tasks include cleaning and organizing the data, performing exploratory analysis, and new findings.

**3.Skills:**
Data cleaning, Data Analysis, Data Modelling, PostgreSQL Join tables, Problem Solving, SQL Query, CTE used, Pivot Table

**4. Technologies:** SQL, PostgreSQL, Excel, Pivot Table

**5. Findings :** Identifying trends, patterns and sales-related challenges.

- Which countries have the most invoices?

- Lets invite the artist who have written the most rock music in our dataset. Write a query that returns the Artist name and total track count of top 10 rock bands

first.
